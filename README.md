# William's Home

A modern family expense management application built with React, TypeScript, and Tailwind CSS.

## Features

-   Modern and responsive UI
-   Dark/Light theme support
-   Multi-language support
-   Family expense tracking
-   Budget management
-   Expense analytics and reports

## Getting Started

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

## Building for Production

To create a production build:

```bash
npm run build
```

## Technologies Used

-   React
-   TypeScript
-   Tailwind CSS
-   Framer Motion
-   Vite
